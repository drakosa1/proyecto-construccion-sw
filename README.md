# Sistema de Registro de Estudiantes

Proyecto desarrollado en Python para el curso de Construcción de Software.

## Funcionalidades

- Registrar estudiantes.
- Mostrar la lista de estudiantes registrados.
- Buscar estudiantes por nombre.
- Validar la edad ingresada.
- Menú de opciones para interactuar con el sistema.

## Tecnologías utilizadas

- Python 3
- Git
- GitHub
- Visual Studio Code

## Control de versiones

El proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto.  
Las mejoras se desarrollan mediante ramas y Pull Requests.
